# Conception Phase

This folder contains the documentation and supporting materials for the Conception Phase of the Finance Analytics Dashboard.

## Conception Document

The conception document outlines the proposed design and technical approach for the project, including:

- Project goal and objectives
- User interface and user flow
- System architecture
- Database structure
- RESTful API design
- Summary and financial calculations
- Technology stack
- Expected dashboard features

## Supporting Materials

The folder also contains the supporting design materials developed during the conception phase:

- **ERD** – illustrates the relationship between the database entities.
- **UI Wireframe** – shows the planned dashboard layout and user interaction flow.
- **Architecture & Data Flow Diagram** – illustrates how the frontend, Flask API and MySQL database communicate.
